# Security & Responsible Disclosure

This repository is a public research workspace. Please do not submit passwords, access tokens, private keys, personal data, or other sensitive information in issues or pull requests.

## Reporting a concern

If you identify a security issue in code published here, please use GitHub's private vulnerability reporting feature if it is enabled for the repository. Otherwise, open a minimal issue that does not disclose exploit details or sensitive data and request a private contact channel.

## Scope and authorization

- Only test systems you own or are explicitly authorized to assess.
- Do not use this repository to facilitate unauthorized access, disruption, credential theft, or privacy violations.
- Follow the applicable laws, platform rules, and third-party service terms.
- Treat public-source findings as leads that require validation, not automatic proof.

No security response-time guarantee is made by this document.
