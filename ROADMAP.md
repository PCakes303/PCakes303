# PCakes303 — Roadmap

This roadmap describes intended areas of development, not completed features. Items move to **In progress** or **Complete** only when there is a public artifact to point to.

## Foundation
- [x] Establish the public profile README
- [x] Document research principles and provenance expectations
- [ ] Publish a first small, well-documented OSINT utility
- [ ] Add a reproducible example with sample or synthetic data

## OSINT & Cyber Intelligence
- [ ] Build a source-aware research workflow
- [ ] Document a domain and internet-infrastructure research case study using suitable public test targets
- [ ] Add structured output and confidence/limitation notes
- [ ] Publish a practical guide to source validation and correlation

## Swarm & Distributed Systems
- [ ] Prototype bounded task delegation between independent workers
- [ ] Add orchestration, logging, and deduplication
- [ ] Explore human review checkpoints and safe stop conditions
- [ ] Document trade-offs between centralized and distributed workflows

## Quality Bar
Every public project should aim to include:
- A clear purpose and scope
- Setup and usage instructions
- Example inputs and outputs that do not expose private data
- Source provenance and known limitations
- Safety, authorization, and responsible-use notes
- Tests or a reproducible validation method where appropriate

Suggestions and constructive collaboration are welcome through GitHub discussions or issues when enabled.
